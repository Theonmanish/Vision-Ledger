# 📖 About VisionLedger

VisionLedger is an **AI-powered environmental verification platform** that combines **Artificial Intelligence**, **Computer Vision**, and **Blockchain Technology** to verify environmental, ESG, sustainability, and infrastructure claims.

Traditional environmental reporting relies heavily on trust and manually reviewed documentation.

VisionLedger transforms this process by providing:

- 🤖 AI-powered evidence analysis
- ⛓ Immutable blockchain verification
- 📄 Enterprise-grade verification certificates
- 📊 Intelligent verification analytics
- 📦 Bulk verification workflows
- 🔔 Real-time notification center
- 📱 Mobile-first Progressive Web App

Every verified claim is securely anchored on the **Ethereum Sepolia Blockchain**, providing transparent, tamper-resistant proof that can be independently verified.

---

## 📊 Multi-Score Confidence Engine

Unlike traditional AI systems that return a single confidence score, VisionLedger evaluates every verification using three independent confidence metrics.

| Score | Purpose |
|--------|----------|
| 👁 Vision Confidence | Image quality and AI object detection certainty |
| 🎯 Claim Match Confidence | How well the uploaded evidence supports the selected claim |
| ✅ Verification Confidence | Final confidence used for verification status |

Verification Status

| Confidence | Result |
|------------|----------------|
| 90 – 100 | ✅ Verified |
| 75 – 89 | 🟢 Likely Verified |
| 50 – 74 | 🟡 Needs Review |
| 25 – 49 | 🟠 Inconclusive |
| 0 – 24 | 🔴 Rejected |

# ⛓ Blockchain Verification

Every successful verification is cryptographically anchored on the **Ethereum Sepolia Testnet**, ensuring that verification results are immutable, transparent, and independently verifiable.

Each blockchain record contains:

- Verification Hash
- Transaction Hash
- Block Number
- Smart Contract Address
- Network Information
- Verification Timestamp
- Verification Status

Users can directly verify transactions through **Sepolia Etherscan** from both the application and the generated certificate.

# 🚀 Running Locally

## Clone Repository

```bash
git clone https://github.com/<username>/Vision-Ledger.git

cd Vision-Ledger
```

---

## Frontend

```bash
npm install

npm run dev
```

---

## Backend

```bash
cd backend

python -m venv .venv

# Windows

.venv\Scripts\activate

# Linux / macOS

source .venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend will run at

```
http://localhost:8000
```

Swagger Documentation

```
http://localhost:8000/docs
```
